# 论文格式要求

> 注：以下格式要求为通用本科/硕士论文格式参考，具体格式应以学校提供的模板为准。本文档仅供参考。

---

## 1. 论文封面

### 1.1 封面内容
- **题目**：简洁明了，不超过25个汉字
- **学院/系**：全称
- **专业**：全称
- **年级**：如"2023届"
- **学号**
- **学生姓名**
- **指导教师**：姓名 + 职称

### 1.2 封面样式
- 题目：二号黑体居中
- 其他信息：小四号宋体居中
- 封面与内页统一，不要页眉页脚

---

## 2. 摘要

### 2.1 中文摘要

**格式要求**：
- 标题"摘要"：三号黑体居中，单倍行距，段前段后各空0.5行
- 摘要正文：小四号宋体，1.5倍行距
- 关键词：3-5个，用分号分隔；"关键词"三字用小四号黑体，关键词内容用小四号宋体
- 字数：本科200-300字，硕士500字左右

**内容结构**：
1. 研究背景（1-2句）
2. 研究目的/问题（1句）
3. 研究方法（1-2句）
4. 研究结果/主要贡献（2-3句）
5. 结论/意义（1-2句）

**示例**：
> 摘要：随着企业数字化转型的深入推进，工作流引擎作为业务流程自动化的核心组件，其设计与实现成为软件工程领域的研究热点。本文针对传统工作流引擎在DAG任务编排场景下存在的可视化程度低、并行分支支持不足等问题，设计并实现了一个基于DDD六边形架构的轻量级DAG工作流执行引擎PowerFlow。该系统采用Java Spring Boot作为后端框架，前端使用React与React Flow实现DAG可视化编辑，支持START、END、DATA_PROCESSING、CONDITION、PARALLEL、JOIN六种节点类型，通过SpEL规则引擎实现动态条件路由。测试结果表明，该系统能够正确完成DAG环检测、拓扑排序执行以及并行分支的同步汇合等功能，执行性能满足非功能需求。本文的研究对于轻量级DAG工作流引擎的架构设计与实现具有一定的参考价值。
>
> 关键词：工作流引擎；DAG执行；六边形架构；规则引擎；并行分支

### 2.2 英文摘要（Abstract）

**格式要求**：
- 标题"Abstract"或"ABSTRACT"：三号Times New Roman加粗居中
- 正文：小四号Times New Roman，1.5倍行距
- Keywords：小四号Times New Roman，关键词首字母大写

## 3. 目录

### 3.1 格式要求
- 标题"目录"：三号黑体居中
- 目录正文：小四号宋体
- 页码：Times New Roman
- 自动生成或手动编辑均可
- 一级标题左对齐，二级标题缩进0.75字符

### 3.2 示例结构
```
目  录

第1章 绪论 ………………………………………………………………… 1
  1.1 研究背景与意义 ………………………………………………… 1
  1.2 论文结构安排 …………………………………………………… 3
第2章 相关技术介绍 …………………………………………………… 4
  2.1 Java EE与Spring Boot框架 ………………………………… 4
  2.2 领域驱动设计与六边形架构 ………………………………… 6
  …
参考文献 ………………………………………………………………… 55
致  谢 …………………………………………………………………… 57
```

## 4. 正文格式

### 4.1 字体与字号

| 位置 | 字体 | 字号 | 格式 |
|------|------|------|------|
| 章节标题 | 黑体 | 三号 | 居中，段前段后0.5行 |
| 一级节标题 | 黑体 | 四号 | 左对齐，段前段后0.5行 |
| 二级节标题 | 黑体 | 小四号 | 左对齐 |
| 正文 | 宋体 | 小四号 | 首行缩进2字符，1.5倍行距 |
| 代码/公式 | Courier New / Times New Roman | 五号 | 居中或左缩进 |
| 图注 | 宋体 | 五号 | 居中，段前0.5行 |
| 表注 | 宋体 | 小五号 | 左对齐 |

### 4.2 页面设置
- 纸张：A4（210mm × 297mm）
- 页边距：上2.8cm，下2.6cm，左3.0cm，右2.5cm
- 页眉：奇偶页不同，奇数页为章节名，偶数页为论文题目
- 页脚：页码，居中，从正文开始编页码（1, 2, 3...）

### 4.3 章节编号
```
第1章 绪论
1.1 研究背景与意义
1.1.1 工作流引擎发展历程
```

### 4.4 段落格式
- 正文章段落：首行缩进2字符，1.5倍行距
- 标题后段落：段前段后0.5行
- 图、表与正文之间：段前段后0.5行

---

## 5. 图和表

### 5.1 图（Figure）

**格式要求**：
- 图号：图1、图2...（章编号，如"图3-1"）
- 图题：图号 + 图题，置于图下方居中，宋体五号
- 图与正文之间：段前0.5行

**排版要求**：
- 图居中排列
- 图宽度不超过页面文字宽度（左右边距内）
- 引用时用"如图1-1所示"

### 5.2 表（Table）

**格式要求**：
- 表号：表1、表2...（章编号，如"表2-1"）
- 表题：表号 + 表题，置于表上方居中，宋体五号
- 表头：加粗，背景色（浅灰）
- 表内容：宋体五号/小五
- 表格宽度不超过页面文字宽度

**示例**：
```
表3-1 功能需求列表

| 需求编号 | 需求描述               | 优先级 |
|----------|------------------------|--------|
| FR-001   | 工作流创建             | 高     |
| FR-002   | 节点配置               | 高     |
| FR-003   | DAG可视化编辑          | 高     |
```

---

## 6. 代码

### 6.1 代码格式要求
- 代码字体：Courier New或Consolas，五号
- 代码块：居中或左缩进，浅灰色背景边框
- 行号：左侧显示（可选）

### 6.2 代码注释
- 代码中的注释用 `//` 或 `/* */`
- 注释行不要用斜体

### 6.3 代码引用
- 引用时用"如图5-2所示"或"代码清单5-1展示了..."
- 代码清单编号：代码清单1、代码清单2...

---

## 7. 公式

### 7.1 公式格式要求
- 公式居中排列
- 公式编号：右对齐，章编号+顺序号，如"(3-1)"
- 公式引用：如"根据公式(3-1)可知"

### 7.2 公式编辑
- 使用公式编辑器（如Word公式编辑器、LaTeX）
- 变量用斜体，数字和函数名用正体

---

## 8. 参考文献

### 8.1 格式要求
- 标题"参考文献"：三号黑体居中
- 文献列表：小四号宋体，1.5倍行距
- 每条文献首行左对齐，后续行缩进2字符（悬挂缩进）
- 顺序编号，使用 [1]、[2] 格式

### 8.2 常用文献类型格式

**期刊文章**：
```
[序号] 作者. 文章题目[J]. 期刊名, 出版年份, 卷(期): 页码.
例：[1] 张三, 李四. 基于DDD的微服务架构设计[J]. 软件工程, 2023, 26(5): 12-18.
```

**书籍**：
```
[序号] 作者. 书名[M]. 出版地: 出版社, 出版年份.
例：[2] Vaughn Vernon. 领域驱动设计精粹[M]. 北京: 电子工业出版社, 2018.
```

**论文集/会议**：
```
[序号] 作者. 文章题目[C]// 会议名称. 出版地: 出版社, 年份: 页码.
```

**网络资源**：
```
[序号] 作者. 资源名称[EB/OL]. 网址. 更新日期/访问日期.
例：[3] React Flow. React Flow Documentation[EB/OL]. https://reactflow.dev/. 2024-01-15.
```

---

## 9. 致谢

### 9.1 格式要求
- 标题"致谢"：三号黑体居中
- 正文：小四号宋体，1.5倍行距
- 不编号

### 9.2 内容建议
- 感谢导师的指导
- 感谢同学/实验室同仁的帮助
- 感谢家人的支持
- 感谢项目/基金的资助（若有）

---

## 10. 附录（可选）

- 附录编号：附录A、附录B
- 内容：不宜放在正文但有参考价值的材料
- 如：问卷调查、完整代码、数据表格

---

## 11. 整体字数要求

| 学历 | 字数要求（正文） |
|------|----------------|
| 本科 | 8,000-15,000字 |
| 硕士 | 30,000-50,000字 |
| 博士 | 80,000-120,000字 |

---

## 12. 查重要求

- 推荐使用知网、维普等查重系统
- 本科重复率通常要求 < 30%
- 硕士通常要求 < 15-20%
- 参考文献、致谢、附录不计入重复率（各学校规定不同）

---

## 13. 论文写作注意事项

1. **语言规范**：使用学术语言，避免口语化
2. **逻辑清晰**：每章有引言和小结
3. **图表规范**：所有图表需有编号和标题，引用时需在正文中提及
4. **引用规范**：所有引用的数据、观点、代码均需注明出处
5. **格式统一**：全文使用统一的字体、字号、行距
6. **避免重复**：摘要与正文、章节之间避免大量重复内容
7. **创新点明确**：在结论部分明确阐述本文的创新点
8. **致谢适度**：致谢部分感谢要真诚、适度

---

*注：以上格式要求仅供参考，具体格式应以学校提供的论文模板和写作规范为准。建议在写作前从教务处或导师处获取最新的论文格式模板。*

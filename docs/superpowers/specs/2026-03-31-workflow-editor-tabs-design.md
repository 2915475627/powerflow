# PowerFlow 工作流编辑器 Tab 布局设计

## 概述

重新设计工作流编辑器页面布局，采用顶栏 Tab 结构，将节点配置、模板管理、执行测试等功能模块化。

## 顶栏 Tab 结构

| Tab | 用途 |
|-----|------|
| 工作流 | 工作流列表 |
| 编辑器 | 画布 + 节点配置/模板管理/执行测试（编辑器子Tab） |
| 监控 | 执行监控（已有功能） |
| 节点配置 | 全局模板管理（独立页面） |

## 编辑器 Tab 布局

```
┌─────────────────────────────────────────────────────────┐
│ [工作流名称输入]                            [保存按钮]   │
├─────────────────────────────────────────────────────────┤
│ [节点配置] [模板管理] [执行测试]     ← 编辑器子Tab        │
├───────────────────────────────────┬─────────────────────┤
│                                   │                     │
│         画布 (ReactFlow)          │   右侧面板          │
│                                   │   (子Tab内容区)     │
│                                   │                     │
└───────────────────────────────────┴─────────────────────┘
```

## 编辑器子Tab 详细设计

### 1. 节点配置 子Tab

**未选中节点时：**
- 显示"请点击画布上的节点进行配置"提示
- 显示节点类型网格（快速添加节点）

**选中节点时：**
- 顶部：模板快速填充选择器（下拉框）
- 下方：节点配置表单（字段根据节点类型不同）
- 底部：应用、删除按钮

### 2. 模板管理 子Tab

**选中节点后：**
- 显示该节点类型对应的模板列表（卡片形式）
- 点击模板：自动填充节点配置（不自动保存，需手动点"应用"）
- 模板卡片显示：名称、备注

**无节点选中时：**
- 提示"请先在画布上选择一个节点"

### 3. 执行测试 子Tab

- 节点ID输入（自动填入当前选中节点）
- Context输入（JSON格式，默认 `{"input": {}}`）
- 执行按钮
- 结果展示区（成功/失败、输出、耗时）

## 节点配置 Tab（独立页面）

### 布局

```
┌─────────────────────────────────────────────────────────┐
│ 节点配置管理                                             │
├─────────────────────────────────────────────────────────┤
│ ┌─ LLM_CALL ─────────────────────────────────────────┐ │
│ │ 模板卡片1: 名称 | 备注 | [编辑] [删除]              │ │
│ │ 模板卡片2: 名称 | 备注 | [编辑] [删除]              │ │
│ │ [+ 新建模板]                                       │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌─ HTTP_REQUEST ─────────────────────────────────────┐ │
│ │ 模板卡片1: 名称 | 备注 | [编辑] [删除]              │ │
│ │ [+ 新建模板]                                       │ │
│ └────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

### LLM模板字段

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 模板名称 |
| nodeType | enum | LLM_CALL |
| config.provider | string | 供应商名称 (openai/anthropic/azure) |
| config.model | string | 模型名称 |
| config.apiKey | string | API Key（加密存储） |
| config.baseUrl | string | 请求地址 |
| config.temperature | number | Temperature |
| config.maxTokens | number | 最大Token数 |
| remark | string | 备注 |
| website | string | 官网链接 |
| active | boolean | 是否启用 |

### HTTP模板字段

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 模板名称 |
| nodeType | enum | HTTP_REQUEST |
| config.url | string | 请求地址 |
| config.method | enum | GET/POST/PUT/DELETE/PATCH |
| config.headers | object | 请求头 |
| config.body | object | 请求体 |
| config.timeout | number | 超时时间(ms) |
| remark | string | 备注 |
| active | boolean | 是否启用 |

## 交互流程

1. 用户点击节点 → 右侧面板显示该节点配置
2. 用户可在"节点配置"子Tab手动填写/编辑字段
3. 用户可在"模板管理"子Tab选择一个模板 → 字段自动填充到配置表单
4. 用户点击"应用" → 节点配置更新（仅更新内存，需保存工作流才持久化）
5. 用户可在"执行测试"子Tab测试单个节点

## 数据流

- 模板数据：后端数据库 → NodeTemplateRepository → NodeTemplateController API
- 节点配置：前端React state → 工作流保存时持久化到后端
- 执行测试：调用 `/api/workflows/{workflowId}/nodes/{nodeId}/test`
